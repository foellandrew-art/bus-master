🚌 School Bus Master Renewal App
A mobile-friendly study tool and mastery tracker for Minnesota School Bus Driver renewals.
🚀 Quick Setup (How to Host on GitHub)
Follow these steps to get your app live on the web:
 * Create a Repository:
   * Log in to your GitHub account.
   * Click the + icon in the top right and select New repository.
   * Name it bus-master and set it to Public.
   * Click Create repository.
 * Upload the File:
   * On the setup page, click the link that says "uploading an existing file".
   * Drag and drop your School_Bus_Master_Guide.html file into the box.
   * Crucial: Rename the file to index.html on GitHub. (GitHub looks for index.html to start the website).
   * Click Commit changes.
 * Activate GitHub Pages:
   * Go to the Settings tab of your repository.
   * Click Pages in the left-hand sidebar (under the "Code and automation" section).
   * Under "Build and deployment" > "Branch", change "None" to main.
   * Click Save.
 * Visit Your App:
   * Wait about 60 seconds. Refresh the Pages screen.
   * You will see a banner that says: "Your site is live at https://[your-username].github.io/bus-master/"
   * Open that link on your phone!
☁️ Enabling Cloud Sync (Optional)
Currently, the app runs in Local Mode, meaning progress is saved to your specific browser/device. To sync progress across multiple devices:
 * Create a free project at Firebase.
 * Enable Anonymous Auth and Firestore Database.
 * Copy your Firebase Config object.
 * In your index.html code, replace the empty __firebase_config logic with your credentials.
